# Aegis Model Card

## Current status

No risk model has been trained, evaluated, selected, or deployed. Aegis Phase 1 contains only data, persistence, and API contracts; it makes no model-performance claims.

## Planned target

A future model is intended to estimate transaction-level risk associated with coordinated payment abuse, including card-testing rings, account farms, identity rotation, and collusive payment clusters. The planned model will be one input to a separate deterministic policy layer, not an autonomous payment decision-maker.

## Sections required before model use

The model card must be completed with evidence from the actual training and evaluation process:

- Training and evaluation dataset versions
- Feature version and feature definitions
- Metrics, including class-appropriate error and cost measures
- Selected operating threshold and the rationale for it
- Known limitations, blind spots, and out-of-scope behavior
- Evaluation design, slices, temporal validation, and reproducibility details

No values are provided for these sections because the model and datasets do not yet exist.
